# 管理员维护：当前每周班表

只维护两张 CSV 表，填写当前每周班数、运营星期和时效备注。

1. 编辑本目录 CSV，保存为 **CSV UTF-8（逗号分隔）**。
2. 在项目根目录运行 `python scripts/manage-data.py apply`。
3. 提交并部署 CSV 和生成的 `src/data/routes.json`、`src/data/flights.json`，刷新网站生效。

命令会先检查填错的代码、重复记录、班数和星期是否匹配。检查失败时不改网站 JSON；只检查不写入用 `python scripts/manage-data.py check`。需要 Python 3 和 Node.js，无需安装额外 Python 库。

## timetables.csv：一行一个单向航班

| 列名 | 内容 | 示例 |
| --- | --- | --- |
| airline | 航司代码 | CA |
| flight_number | 航班号，纯数字，自动补齐4位 | 0987 |
| origin | 实际出发机场 | PEK |
| destination | 实际到达机场 | LAX |
| aircraft | 四位机型代码，可留空；多个用 ` / ` 分隔 | B77W |
| weekly_flights | 每周几班 | 3 |
| weekdays | 周几飞：1周一，7周日，不加空格或分隔符 | 135 |
| note | 一条时效备注，自由文字 | 10月核查，近期可能调整，以航司公布为准 |

上表示例只说明填写格式，不作为真实班表证据。

机型统一使用 `B747`、`B767`、`B789`、`B77W`、`A359`、`A35K` 等四位代码，不混用厂商全名。带字母的型号后缀保留；只知道系列时可填 `B747`、`B767`，不要猜具体子型号。生成命令也会将 `Boeing 747` 自动规范为 `B747`，未知格式会提示修改。页面以纯文字展示机型代码。

`weekly_flights=3`、`weekdays=135` 表示每周3班、周一三五飞。每天飞填 `7`、`1234567`。往返分别填，每个航班号和方向只占一行。当前模型每个运营日该航班执行一次；同航线一天多班用不同航班号各填一行。

修改班期直接改这一行；新增复制一行；已不运营的航班删掉这一行。备注不解析日期、不自动过期、不改变地图显示，可以随实际情况更新。每条航班需有备注，避免资料时效无从判断。

**现有446条记录以2026-10-20资料为基础；2026-10-21修复加航完整周模式及CA987漏录。** 逐项原值、新值、来源与适用期见 [往返复核](../reference/round-trip-review-20261021.json)。本次全量一致性扫描不代表全部航班事实都已重新联网核实。

填写来源有效期内完整的每周运营模式，不要把抓取日起至周末／换季日前剩余的执行日期当作每周频次。仅执行一天的调时或换号航班不能当作长期周班表。备注注明资料日期和有效期；换季交界周实际执行数量可以不同，不能通过补造星期强制对齐。

导入前会检查同航司同机场对的双向周班总量、单航班频次分布，以及 `scripts/data/round-trip-pairs.json` 中明确声明的 AC 常规航班对与 CA987/988。返程不要求相同的出发星期，也不按航班号奇偶自动配对。其他航班的结构校验不能证明其真实航班号关联；真实单向、三角运营或换号需核实并调整模型后再导入。校验失败不会替换网站 JSON，无班表航线仍然有效。

## routes.csv：一行一家航司的一对机场

| 列名 | 内容 |
| --- | --- |
| airline | 航司代码 |
| origin | 亚太端机场 |
| destination | 北美端机场 |
| note | 航线备注，可留空 |

地图按这张表画线。无班表时仍显示航线，提示“班表未录入”。增加航班前先确保这张表有对应航线。移除航线时同时删除关联班表；删除一条航班不会自动删除航线。不要把尚未开航计划放进当前表。

机场卡片只显示机场基本资料和目的地／班表数量。机场、航司基础目录在 `src/data/airports.json`、`airlines.json`；日常班期调整不需要改它们。

基础目录也已精简：机场只填代码、中英文名、城市、国家／地区、地图区域和经纬度；航司只填代码、中英文名、国家／地区和联盟。不需要资格示例、来源编号、核查日期或运营状态等附加记录。

## Excel 注意事项

从“数据 → 从文本/CSV”导入，选 UTF-8、逗号分隔。把代码、航班号和星期列设为**文本**，避免自动去掉前导零；保存为 CSV UTF-8。保留英文表头及列顺序。备注有逗号或换行时，Excel 会自动处理引号，文本编辑器需按标准 CSV 引号规则填写。

## 文件说明

当前脚本只读取本目录的两张 CSV，生成 `src/data/routes.json` 和 `src/data/flights.json`。页面班数和星期分成两行，例如“每周3班 / 3 Flights per week”下一行“一 三 五 / MON WED FRI”；每周7班不再列出星期。

校验只检查数据一致性，不会联网核实航班事实。机场／航司必须已收录；需新增机场或航司时先补齐基础目录。
