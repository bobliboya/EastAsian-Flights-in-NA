# 联盟标识

获取于2026-10-20，商标属于各联盟。只用作身份识别。

- `OW.svg`：阿拉斯加航空公开的图标包 `https://unpkg.com/@alaskaairux/icons@4.3.0/dist/restricted/oneworld.svg`，保留圆形标识。
- `SA.svg`：`https://www.logo.wine/a/logo/Star_Alliance/Star_Alliance-Logo.wine.svg`，仅保留几何星形，移除字标并收紧SVG视框。
- `ST.svg`：`https://www.logo.wine/a/logo/SkyTeam/SkyTeam-Logo.wine.svg`，保留圆形标识，收紧SVG视框。

页面显示18px联盟小标识，保留圆形展示样式；名称通过悬停或键盘聚焦提示显示，界面不附加联盟文字。无联盟不显示占位图标。成员归属读取 [航司目录](../../data/airlines.json)，证据见 [航司标识说明](../airlines/README.md)。
