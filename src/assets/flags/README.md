# 国旗与地区旗帜

8份SVG取自 [flag-icons](https://github.com/lipis/flag-icons)，原始MIT许可和版权声明保存在 [LICENSE](LICENSE)。

当前使用 `cn`、`hk`、`tw`、`jp`、`kr`、`sg`、`us`、`ca`。仅保留机场或航司目录实际使用的旗帜；朝鲜与澳门没有已收录服务，未保留对应素材。

页面由 `src/js/app.js` 的 `FLAG_REGIONS` 按各机场／航司自己的 `country_or_region` 映射；选中后的筛选标签只显示代码，下拉选项保留旗帜。增加地区时须同步目录、映射和素材。
